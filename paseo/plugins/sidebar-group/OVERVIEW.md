좌측 사이드바 상단에 "그룹" 메뉴를 추가합니다(영어 앱에서는 "Groups"). 연결된 모든 호스트의 워크스페이스를 프로젝트별 박스로 묶어 보여주고, 각 워크스페이스 안에는 에이전트를 부모와 자식 트리로 표시합니다. 워크스페이스나 에이전트를 누르면 해당 화면으로 이동합니다.

프로젝트는 섹션으로 묶입니다. 커스텀 그룹을 지정한 프로젝트는 그 그룹에, 나머지는 프로젝트가 들어 있는 상위 디렉토리별로 묶입니다. "그룹 편집"을 켜고 프로젝트의 "그룹 변경"을 누르면 기존 그룹을 고르거나, 새 그룹을 만들거나, 상위 디렉토리 자동 묶기로 되돌릴 수 있습니다. 프로젝트가 하나도 남지 않은 그룹은 자동으로 사라집니다.

커스텀 그룹은 데몬의 플러그인 설정에 저장되므로 같은 호스트에 연결한 모든 기기에서 똑같이 보입니다. 워크스페이스, 프로젝트, 브랜치 검색과 상태 필터를 지원하고, 백그라운드 워크스페이스와 에이전트도 켜서 볼 수 있습니다. 보관된 워크스페이스는 표시하지 않습니다.

각 카드의 보관 버튼은 한 번 누르면 바로 보관됩니다. ⋮ 버튼은 사이드바 워크스페이스 메뉴와 같은 작업(경로 복사, 브랜치 이름 복사, 이름 변경, 상단에 고정, 레이블, 파일 관리자에서 열기, 보관)을 제공합니다. 파일 관리자에서 열기는 데스크톱 앱에서, 현재 화면이 연결된 호스트의 워크스페이스에만 표시되며 데몬 머신에서 폴더를 엽니다.
