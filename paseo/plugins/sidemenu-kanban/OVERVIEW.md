좌측 사이드바 상단에 "칸반" 메뉴를 추가합니다(영어 앱에서는 "Kanban"). 연결된 모든 호스트의 워크스페이스를 현재 상태에 따라 입력 대기, 확인 필요, 실행 중, 실패, 완료 컬럼으로 나눠 보여줍니다.

각 카드에는 워크스페이스 제목, 프로젝트와 브랜치, Paseo가 표시하는 상태 문구, 상태가 바뀐 뒤 지난 시간, 열린 에이전트 수, diff 크기가 나옵니다. 카드를 누르면 해당 워크스페이스로 이동합니다. 보드 위의 칩으로 프로젝트별로 걸러볼 수 있고, 사이드바 메뉴에는 입력 대기나 실패 상태인 워크스페이스 수가 표시됩니다.

앱이 이미 가진 워크스페이스와 에이전트 정보만 읽으며 외부로 보내는 데이터나 설정은 없습니다. 보관 중이거나 백그라운드인 워크스페이스는 숨깁니다. 넓은 창에서는 컬럼이 가로로 나란히, 모바일이나 좁은 창에서는 세로로 쌓여 표시됩니다.
